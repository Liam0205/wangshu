# #299：os.time 的字段读取也要经过表协议

`os.time` 的日期计算和普通 `__index` 分别工作，并不能证明二者组合正确。该函数及
`getBoolField` 使用 `RawGet`，跳过元表，导致默认日期表报必填字段缺失。

修复复用已有 `IndexWithMeta`，同时覆盖六个数值字段和 `isdst`；错误传播、函数与表链
查找都由同一个 VM 入口处理。整数转换、可选字段默认值与 DST 算法没有改写。

回归测试在 `test/language/ostime_index_test.go`，覆盖字段顺序、已有字段、不存在的
可选／必填字段、查找副作用、表链与环、GC、嵌套调用及每个字段处理函数抛错。17 个子用例
的期望值均用未经 stub 的 PUC Lua 5.1.5 核对；修复前 16 个失败、已有字段的对照通过。

可复用的检查方法：审查库函数里的原始访问时，核对参考 C API 是 `lua_getfield` 还是
`lua_rawget`；不能仅根据底层存储形式选择访问函数。测试必须确实调用待检查的库函数，
不能用确定性 stub 替换后再声称验证了其协议。

机制说明见 [标准库设计 §9.1.1](../../../docs/design/p1-interpreter/10-stdlib.md)。
